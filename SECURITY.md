# Security Policy

## Reporting a Vulnerability

Do not open a public issue for security vulnerabilities.

Email: ntudu040@gmail.com

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

You'll get a response within 48 hours. Once fixed, a public advisory will be posted.

## Scope

- The `skmp` CLI binary
- The `registry/index.json` and skill source URLs
- The npm wrapper and install script

## Out of Scope

- Skills published by third parties (their content is their responsibility)
- Issues in harness tools (pi, Claude Code, etc.) themselves
